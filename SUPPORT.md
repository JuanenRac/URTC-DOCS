## ✉️ Direct Technical Inquiries
For questions about the architecture, the contracts between repositories or the capability matrix:
Email: `electrohobby3d@gmail.com`

## 🐛 Bug Reports
If you found a statement in a document that does not match the repository it describes, or an error in a tool, please open a **GitHub Issue** in this repository and name the sentence and the repository.
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?
- Questions about running a specific service belong in that service's own repository.
- Please do not use Issues for "How to" questions.
